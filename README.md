# CIIP Web App v0.1

Aplicación web estática/PWA basada en CIIP Operating System v2.0.

## Uso
- Abrir `index.html` en un navegador de escritorio.
- Para instalar en iPhone y activar el modo sin conexión, publicar la carpeta en GitHub Pages o Netlify mediante HTTPS; abrir en Safari y usar Compartir > Añadir a pantalla de inicio.
- Notas y estados: `localStorage` por navegador; exportar/importar desde **Datos**. No hay sincronización multiusuario ni precios en tiempo real.
- Actualización de datos: regenerar `index.html` con la nueva exportación del Excel.

## Seguridad
No contiene credenciales ni claves. No almacenar datos sensibles en notas locales. No ejecuta operaciones.
